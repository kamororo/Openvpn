# Openvpn

«Openvpn» یک برنامه‌ی مستقل OpenVPN برای اندروید است. دو کار می‌کند:

- **ساخت خودکار اکانت رایگان** و اتصال به آن
- **اتصال به کانفیگ‌های شخصی خودتان** (فایل‌های `.ovpn`)

نسخه‌ی فعلی: **۱٫۵** (کد ۶) — پکیج `com.renamer.openvpn`

سازنده: **کامیار** — کانال تلگرام: [@internet_azad_2026](https://t.me/internet_azad_2026)

## نصب

فایل APK را از بخش **Releases** همین ریپو دانلود و نصب کنید (سایدلود).

## اتصال به اکانت رایگان

1. اول فیلترشکن خودتان را روشن کنید، بعد روی دایره‌ی بزرگ وسط صفحه بزنید و کمی صبر کنید تا وصل شوید.
2. با چیپ **«انتخاب کشور»** که داخل دایره است، کشور را انتخاب کنید.
   بعد از انتخاب، پرچم و نام همان کشور روی چیپ نشان داده می‌شود.
3. برای قطع اتصال، دوباره روی دایره بزنید.

## اتصال به کانفیگ شخصی

1. به زبانه‌ی **«Open vpn»** بروید.
2. با دکمه‌ی **+** یک فایل `.ovpn` ایمپورت کنید.
3. روی کانفیگ خودتان بزنید تا انتخاب شود — پس‌زمینه‌اش سبز کمرنگ می‌شود.
4. روی دایره‌ی اتصال بزنید.

## دایره‌های سلامت کشورها

جلوی هر کشور یک یا دو دایره‌ی کوچک نشان داده می‌شود:

| علامت | یعنی |
|---|---|
| 🟢 یک دایره‌ی سبز | سالم است |
| 🟢🟢 دو دایره‌ی سبز | سالم است و با اینترنت خودتان هم وصل می‌شود |
| 🔴 یک دایره‌ی قرمز | ناسالم است |
| 🟢🔴 سبز + قرمز | سالم است ولی وصل نمی‌شود |
| ⚪ دایره‌ی خاکستری توخالی | هنوز در حال تست است |

> **نکته‌ی مهم:** برای این‌که دایره‌ها درست نشان بدهند هر کشور با اینترنت
> شما وصل می‌شود یا نه، **فیلترشکن خودتان را خاموش کنید** تا تست روی
> اینترنت خام و بدون واسطه انجام شود. وقتی فیلترشکن روشن است، تست از
> مسیر همان فیلترشکن می‌گذرد و نتیجه‌اش مربوط به اینترنت خودتان نیست.

## رنگ‌های دایره‌ی اتصال

| رنگ دایره | وضعیت |
|---|---|
| آبی کمرنگ | هنوز اکانتی ساخته نشده |
| قرمز کمرنگ | اکانت آماده است ولی وصل نیست |
| سبز کمرنگ | وصل است |

## ساخت (Build)

نیازمندی‌ها:

- JDK (پوشه‌ی `tools/jdk` در فضای کاری)
- Android SDK با `android.jar` مربوط به API 34
- وابستگی‌های OpenVPN در `/tmp/ovpn_build/deps/` (طبق `build.sh`)

```sh
bash build.sh
```

> **هشدار:** بیلد عمومی با یک کی‌استور دیباگ امضا می‌شود که در اولین
> اجرا ساخته می‌شود. هرگز فایل کی‌استور نسخه‌ی نهایی (release keystore)
> را وارد گیت نکنید.
